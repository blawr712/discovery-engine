# v0.4 Platform Specification

## Objective

Turn validated file-backed runs into a queryable local platform for historical
comparison, change detection, and future dashboards without coupling storage
to market-data collection or scoring.

## Sprint 1: Historical Data Foundation

### Increment 1: Offline Run Index

- Index only completed runs through the existing validated checkpoint loader.
- Store manifests and ordered per-company results in a versioned SQLite schema.
- Make repeated indexing idempotent and transactional.
- Preserve complete JSON payloads while exposing common query columns.
- Keep run directories and exports as the source of truth.
- Initialize no market-data, evidence, or AI provider during history actions.
- Provide an offline database summary for operational verification.

### Increment 2: Run Comparison and Change Detection

- Compare any two indexed runs entirely offline.
- Classify universe entrants, exits, retained equities, status transitions,
  successful-candidate rank changes, score changes, and data-quality changes.
- Report the ten largest rank gains and declines.
- Summarize status-transition and country/sector composition changes.
- Export deterministic JSON and review-ready CSV artifacts.

### Increment 3: Candidate Timelines and Weekly Change Reports

- Export chronological ticker status, candidate-rank, score, confidence, and
  fundamental data-quality timelines across every indexed appearance.
- Select the latest pair of complete indexed runs with matching universe sizes.
- Identify promotions into and demotions from the successful candidate set.
- Flag fingerprint differences so configuration changes are not mistaken for
  purely market-driven movement.
- Export a readable Markdown briefing with detailed JSON and CSV artifacts.

### Increment 4: Read-Only Local Dashboard

- Serve an offline dashboard exclusively on the loopback interface.
- Open the SQLite history database in enforced read-only mode.
- Explore indexed runs and filter candidates by status, country, ticker, and
  company name without initializing market-data or AI providers.
- Inspect per-ticker timelines and the latest comparable weekly movement report.
- Use a self-contained responsive interface with no external web dependencies.
